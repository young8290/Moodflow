# moodflow-mailbox

工作区的纯数据、存储与只写收件协议，不依赖网络、Tauri、Windows 或 AI 客户端。最多 200 个会话、每会话 200 条、单条 16384 UTF-16；写入必须完整、原子、检查 revision。流式内容只在内存，按序累积且完成后一次提交；取消、超限、失序不能落盘。

会话以 UUID 定位，收文件必须明确指定会话；目录和文件名不用于猜测关联。消息只进入工作区，Buffer 暂存由用户显式审核，不得调用发送。终端输出不是聊天消息。外部协议不得提供读取、搜索或执行工具。

测试只使用临时目录与合成消息，覆盖跨实例冲突、容量、模型冻结、流式失败和墓碑，不记录正文。
