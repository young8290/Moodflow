# moodflow-sync

平台无关的同步协议、端到端加密和三方合并。文件夹与 WebDAV 必须实现同一 Backend 条件写入接口，不能用“读一次再无条件覆盖”模拟 CAS。缺失、未下载、占位和删除是不同状态；只有永久墓碑表示删除，不根据设备时间判胜。

默认端到端加密，固定 Argon2id 参数、随机 XChaCha20-Poly1305 nonce、数据集和对象身份 AAD。恢复短语及派生密钥不能 Debug、落日志或存明文。明文模式必须显式选择。密码库不能参与默认同步；本机路径、剪贴板、工作区内容和捕获临时资产不得自动纳入。

并发修改时远端获胜，应用前必须保存本机冲突副本。先 CAS 远端清单，再逐条核验本机 revision；任一失败不能丢失原稿或隐式复活墓碑。不可用的媒体只延后，不作删除。所有数据和数量有界，不做远端垃圾回收。测试使用两个合成副本和内存后端，覆盖离线编辑、断连、冲突、墓碑、篡改和跨数据集重放。
