# moodflow-capsule

平台无关的资料库。不得依赖 Tauri、Windows API 或网络。每条一个 UUID 命名的 Markdown 文件，front matter 与 XSIME Capsule 的公开格式兼容；未知字段必须保留。

所有读写有界，写入与删除检查 SHA-256 revision。原子发布前再次检查磁盘内容；多实例通过目录锁协调。不得把正文、标题或文献字段写入日志。密码只在独立加密库保存，禁止接受明文 password 条目。

搜索缓存只保存本机资料，外部编辑在刷新时载入，编辑/删除始终读取磁盘复核。测试只用临时目录，覆盖并发覆盖、目录穿越、损坏条目隔离、配额和往返兼容。
