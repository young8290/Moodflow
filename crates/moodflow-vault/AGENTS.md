# moodflow-vault

平台无关的加密密码库和 TOTP 逻辑。禁止 Tauri、Windows 或网络依赖；DPAPI、桌面锁定与敏感剪贴板由宿主实现。

- 每条以独立的 XChaCha20-Poly1305 随机 24 字节 nonce 加密，AAD 绑定格式版本、库 UUID 与条目 UUID；整份密文快照再加密一层，避免泄露标题、账号与条目索引。
- 随机 256 位主密钥用 Argon2id（64 MiB、3 次、1 通道）从用户口令派生的密钥包装。宿主必须再用当前用户 DPAPI 保护包装记录，不能保存明文密钥或只做 UI 口令门禁。
- 不对任何含密钥或密码的类型实现 Debug；明文临时缓冲与字段在释放时清零，错误只返回固定代码。JSON / IPC 的宿主副本也须按敏感数据处理。
- 每次写入检查原文件 revision，目录锁串行化多实例，先写临时文件再原子发布。不自动修复损坏文件、覆盖已有库或丢失冲突。
- 有界条目和文件；TOTP 覆盖 RFC 6238 SHA-1/256/512 官方向量。不得自动填充、模拟粘贴、发送到 Buffer 或联网。密码库不能参与普通资料搜索或默认同步。

任何交付须记录 Windows DPAPI、锁定和剪贴板验证；密码库与同步的加密方案还须按二期计划交安全评审。
