# 逐帧动作说明

格内坐标：每格 256 × 384，地面线 y = 320，中线 x = 128，标准站姿高约 200 px。
“第 n 帧”从 1 数起；`layout.json` 里的 `frame` 从 0 数起（第 1 帧 = frame 0）。
循环动作的最后一帧要能接回第 1 帧。所有描述都可以直接抄进提示词的格子清单。

---

## idle（6 帧，1100 ms 一轮，循环）—— 平时自在地待着

| 帧 | 描述 |
|---|---|
| 1 | 标准站姿：面朝前，眼睛睁开，嘴角微笑，双手自然垂在身侧（和格 15 一样） |
| 2 | 吸气：身体微微被压扁（宽 +3%、高 −3%），表情不变 |
| 3 | 身体回弹略微拉长（高 +2%），头顶比第 1 帧高约 4 px |
| 4 | 回到标准站姿 |
| 5 | 眨眼：眼睛闭成两条弧线，其余同第 4 帧 |
| 6 | 睁眼，同第 1 帧（接回第 1 帧） |

## running-right（8 帧，1060 ms 一轮，循环）—— 面朝右跑

整组面朝画面右侧，身体前倾约 10°，手臂前后摆。

| 帧 | 描述 |
|---|---|
| 1 | 接地：右脚在前着地，左脚在后，身体最低 |
| 2 | 下压：身体略扁，重心在右脚 |
| 3 | 蹬起：左脚往前摆，身体升高约 8 px |
| 4 | 腾空：两脚都离地一点，身体最高，身后可有两三条速度线 |
| 5 | 接地：左脚在前着地，右脚在后，身体最低 |
| 6 | 下压：身体略扁，重心在左脚 |
| 7 | 蹬起：右脚往前摆，身体升高约 8 px |
| 8 | 腾空：两脚都离地一点，身体最高（接回第 1 帧） |

## running-left（8 帧，循环）—— 面朝左跑

默认**不画**，由工具把 running-right 水平镜像得到。只有形象左右不对称时才画：与 running-right 逐帧对应，朝向改成画面左侧。

## waving（4 帧，700 ms 一轮，播两轮）—— 打招呼

| 帧 | 描述 |
|---|---|
| 1 | 笑眼（弯成月牙），右手从身侧抬到胸前 |
| 2 | 右手举过头顶，手掌张开朝前 |
| 3 | 右手向外挥（往画面右侧），身体微微倾向左 |
| 4 | 右手向内挥（往画面中间），身体回正（接回第 2 帧的感觉） |

## jumping（5 帧，840 ms 一轮，播一次）—— 吓一跳 / 落地

| 帧 | 描述 |
|---|---|
| 1 | 下蹲：身体被压扁（宽 +12%、高 −12%），眼睛睁大，脚踩地面线 |
| 2 | 起跳：身体拉长（高 +10%），脚刚离地约 30 px，手臂向上 |
| 3 | 最高点：脚离地约 90 px，身体圆润，眼睛睁大或星星眼，头顶可有一个小“!” |
| 4 | 下落：脚离地约 35 px，身体略拉长 |
| 5 | 落地：身体压扁（宽 +8%、高 −8%），脚踩地面线，表情回到微笑 |

## failed（8 帧，1220 ms 一轮，播一次）—— 我们出错了，小小的委屈

温和，不夸张；不要倒地、不要大哭、不要文字或符号。

| 帧 | 描述 |
|---|---|
| 1 | 愣住：眼睛变成两个小圆点，头顶右上方一个小“!” |
| 2 | 冒汗：额角一滴蓝色汗珠，嘴变成小波浪线 |
| 3 | 眼睛变成两个小“×”，汗珠还在（晕乎乎，只持续这一帧） |
| 4 | 委屈：眉毛八字，眼睛含泪（下眼睑有一点蓝），双手握在胸前 |
| 5 | 一侧掉下一颗泪滴，身体微微缩起 |
| 6 | 另一侧掉下一颗泪滴 |
| 7 | 用手背擦眼睛 |
| 8 | 吸吸鼻子，眉毛还是八字但嘴角放平，准备回到平时 |

## waiting（6 帧，1010 ms 一轮，循环）—— 闭眼打盹

| 帧 | 描述 |
|---|---|
| 1 | 闭眼（两条下弯的弧线），嘴是一条短横线，头顶右上方一个很小的“z” |
| 2 | 同上，“z”稍大，身体微微下沉 1–2 px |
| 3 | “z”再大一点，往右上飘 |
| 4 | 第二个小“z”出现在第一个下方 |
| 5 | 两个“z”继续变大上飘，身体回升 |
| 6 | 最大的“z”快淡出，小“z”还在（接回第 1 帧） |

头的位置全程稳定（换装锚点）。

## running（6 帧，820 ms 一轮，播两轮）—— 专注结束，开心地原地小跑

面朝前（或略侧），双手握拳在身侧前后摆，表情开心（眯眼笑或嘴张开）。

| 帧 | 描述 |
|---|---|
| 1 | 左脚抬起，右脚着地，身体最低 |
| 2 | 两脚着地，身体回升 |
| 3 | 右脚抬起，左脚着地，身体最高，身侧有两条小汗线或闪光 |
| 4 | 左脚抬起（同第 1 帧，手臂相反） |
| 5 | 两脚着地 |
| 6 | 右脚抬起（接回第 1 帧） |

## review（6 帧，1030 ms 一轮，循环）—— 专注中，认真看

眼睛眯起、眉头微皱（认真，不是生气），右手拿一个小放大镜（或小本子）在身前。头的位置全程稳定（换装锚点）。

| 帧 | 描述 |
|---|---|
| 1 | 放大镜在身前偏左，眼睛看向左 |
| 2 | 放大镜移到正中 |
| 3 | 放大镜在身前偏右，眼睛看向右 |
| 4 | 放大镜回到正中，轻轻点头（头低 2 px） |
| 5 | 放大镜偏左，额角一颗很小的汗珠（专注） |
| 6 | 放大镜回正中，汗珠消失（接回第 1 帧） |
