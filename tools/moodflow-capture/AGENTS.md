# moodflow-capture

Windows 独立采集进程，不进入 TSF 或 Hub 的输入线程。stdin 首行是有界 JSON 请求，其后只接受 stop；stdout 只输出一份有界 JSON 结果，错误用固定代码，正文、窗口标题、OCR 和路径不进日志。

WGC 为首选，监视器截图可回退 DXGI。录制、滚动与延时任务必须持续检查交互桌面、密码输入和停止信号；睡眠／失活后取消且不得自动恢复。像素、尺寸、帧率、时长、文件和输出文字均有上限。失败的临时资产不得发布。

通用尺寸、拼接、资产与保留逻辑在 moodflow-capsule::capture；Windows API 仅在 windows 模块。测试只用合成图片和临时文件；不得为验证而截取用户桌面，真实采集需隔离测试环境或用户明确选择。
