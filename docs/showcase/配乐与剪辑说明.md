# Moodflow 产品展示视频 · 配乐与剪辑说明

- 成片：`moodflow-showcase.mp4`（1920×1080，30 fps，H.264，**带音效轨**：打字、卡片弹出、转场、组合键、logo 叮声；时长 4 分 31.5 秒）
- 只有画面的 `video-only.mp4` 和只有音效的 `sfx.wav`（48 kHz 单声道）体积大，不放进仓库；需要时按 [README](README.md) 在 `source/` 里重新生成
- 逐场时间：`timeline.json`（每场的开始秒数、时长、标题、状态标签）
- logo：用的是品牌原图（仓库 `assets/brand/`），视频里的 `assets/logo-horizontal.png`、`assets/mark.png` 是它的裁切副本
- 改了画面想重出：见 [README](README.md)

> 视频里的界面是演示动画，依据产品文档制作，按「功能全部开发完成」的样子展示，以 Windows 为主，Android 只做一段预览。

## 1. 分段与节奏（配乐卡点）

| 段落 | 时间 | 内容 | 建议情绪 |
|---|---|---|---|
| 片头 | 0:00–0:07.5 | logo 从左往右展开，**1.6 秒一声铃**，2.6 秒字标与标语出现 | 轻、亮，留白 |
| 一览 | 0:07.5–0:16.5 | 四张卡片依次弹出，晴晴挥手 | 主旋律进入 |
| **心情（重点）** | 0:16.5–2:25.5 | 心情天气、只看节奏、解释与自评、桌宠、暖心话、对话、情绪日记、温柔改写、休息与专注、晚间小结与周信、情绪看板、隐私 | **全片的情感核心**：温暖的钢琴或木吉他，旋律最完整的一段放这里；2:02.5 情绪看板处可以有一次抬升 |
| 输入法 | 2:25.5–3:14.5 | 打字、候选矩阵、Buffer、剪贴板历史、并击 | 转轻快，有律动（打字音效很密，音乐可以稍压低） |
| 效率工具 | 3:14.5–4:11.5 | 截图取字、资料库、密码库、Buffer 翻译润色、还有更多 | 轻快、有效率感 |
| Android 预览 | 4:11.5–4:23.5 | 手机键盘、九宫格 | 清爽、轻 |
| 片尾 | 4:23.5–4:31.5 | logo 与标语，晴晴挥手（0.2 秒处一声铃） | 收束，最后一个和弦落在 4:29 左右 |

每场切换处有 0.35 秒淡入淡出，具体秒数见 `timeline.json`。整体建议 **90–105 BPM**；如果只用一首曲子，选 4 分半以上的，把最温暖完整的段落对到「心情」段（0:16–2:25）。

## 2. 轻音乐推荐

**首选可商用、免费的曲库**（使用前请再看一眼各自最新的授权条款，署名要求以官网为准）：

| 曲库 | 怎么找 | 授权要点 |
|---|---|---|
| Pixabay Music | 搜 “acoustic happy”、“soft piano”、“lofi chill”、“ukulele” | Pixabay 内容许可：可商用、无需署名 |
| YouTube 音频库（YouTube Studio → 音频库） | 情绪选「明亮 / 平静」，类型选「原声 / 氛围」 | 多数曲目可在任何视频中使用，部分要求署名（列表里会标出） |
| Kevin MacLeod（incompetech.com） | 例如 *Carefree*（轻快）、*Wallpaper*（轻柔） | CC BY 4.0，须署名 |
| Bensound | 例如 *Sunny*、*Ukulele*、*Little Idea*、*Tenderness* | 免费授权须署名，条款有更新，使用前核对 |

**风格参考**（只作方向，正式使用要买授权）：

- 木吉他 + 尤克里里 + 轻打击乐：输入法、Android 段的轻快感；
- 钢琴 + 弦乐铺底（接近日系治愈系配乐的感觉）：晴晴段的温柔感；
- 钢片琴 / 钟琴的点缀音：适合 logo 出现、卡片弹出这类小动效的卡点。

**两种配法**：

1. **一首到底**：选一首 4 分 30 秒以上、温暖的原声 / 钢琴曲，输入法段打字声密集处把音乐压低 2–3 dB；
2. **两段拼接**：片头到心情段用温柔钢琴（0:00–2:25）→ 输入法、效率工具到片尾换轻快原声（2:25–4:31），交接处在 2:25 的场景淡入淡出里做 1–2 秒交叉淡化。

## 3. 后期建议

- 如需配旁白，字幕已经在画面下方；旁白稿可以直接用每场的大标题 + 小字（`timeline.json` 里有标题）。
- 片头和片尾的 logo 用的是品牌原图（`assets/logo-horizontal.png`），后期加片头卡或角标时也用原图，不要重画。
- 需要竖版（9:16）或 1 分钟精简版，可以在 `video.html` 里调场景时长与布局后重出。
- **音效与配乐**：视频里的音效（打字、弹出、转场、铃声）已经混在成片里，配乐另加一轨即可，两者不冲突。建议配乐整体比音效低 6–10 dB；
  想单独调音效，用 `video-only.mp4` + `sfx.wav` 重新混。音效是程序合成的，没有外部素材版权问题。
