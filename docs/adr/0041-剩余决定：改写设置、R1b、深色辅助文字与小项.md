# 0041 剩余决定：改写设置、R1b、深色辅助文字与几个小项
- 状态：已接受（产品手册 V1.5 已同步，2026-10-15）
- 日期：2026-10-15；提议人：D；待 A（输入法核心、协议）、B（R1b）、C（改写、周信）、E（文案、合规）事后评审，不同意的可直接改

## 背景
交接文档里还有几项一直“等某个角色决定”：R1b 要不要在协议里加字段（A，ADR 0008 第 5 条）、温柔改写的起始风格与文本来源
放在哪里（FR-SET-10 写了 `rewrite.default_style`，但开始改写的是核心）、首次使用说明放哪（FR-RWR-06，A / C / D 待定）、
`ReplaceBackward` 在个别宿主表现不好时怎么办（FR-RWR-04）、深色 `--mf-text-3` 差一点到 4.5:1（D-09）。
用户要求不再等，由 D 逐项决定并实现。

## 决策
1. **改写的起始风格与剪贴板来源放在输入法配置**（`moodflow.rewrite_style`：gentle / polite / concise / structured，出厂 gentle；
   `moodflow.rewrite_clipboard`：出厂开）。理由：开始改写、读剪贴板都在核心，放 Hub 设置还要经 MFP 下发；与已有的
   `moodflow.rewrite_hotkey` 同一处，设置页照样能改（写输入法配置）。10 第 6.2 节的 `rewrite.default_style` 不再使用。
   认不出的风格按“更温和”；关掉剪贴板来源后，没有刚上屏的文字时只提示“先上屏一句再改写哦”。
2. **只插入不替换的宿主名单** `moodflow.rewrite_insert_apps`（通配符，出厂空）：命中时改写“最近上屏”的文字也走插入，原文留着。
   兼容测试（A-11）发现哪个程序删不准，就把它加进出厂值；用户也能在 `config.toml` 里自己加。设置页暂不提供编辑（高级项）。
3. **首次使用说明**放在 Hub 给出同意 ⑥ 的地方：首次引导勾选“温柔改写”时、设置“温柔改写”开着时，显示已有文案
   `rewrite.first_use_notice`（文字会发给 AI 服务；公开发布 AI 生成内容时请主动说明，C-LAW-05 第十条）。
   改写前必须先同意 ⑥，所以用户在第一次改写前一定看到过它。核心的气泡不再加说明（气泡 1.5 秒太短）。
4. **R1b 拼音手误**：MFP `comp` 增加可选字段 `invalid`（只在 `update` 且为真时出现，不含编码内容，协议允许新增可选字段）。
   核心只对全拼方案判断：组字串切不成“每段都是某个标准音节的前缀”时为非法（全拼允许简拼，`zg`、`bjdx` 合法；`ii`、`uu`、
   `zhv` 非法）；双拼、码表方案不判断。Hub 把“非法组字后 600 ms 内退格”记为 `typo`，与 R1 共用事件和 1 秒去重，也计入 `typo_cnt`。
   `protocol/mfp.schema.json` 同步。
5. **深色 `--mf-text-3` 改为 `#9a9389`**：在 `--mf-bg` / `--mf-surface` / `--mf-surface-2` 上分别为 5.72 / 5.15 / 4.57 : 1，
   12 px 小字也达到 4.5:1，仍明显比 `--mf-text-2` 淡（1.43:1 的差距）。浅色值不变。
6. **小项**：`hotkey.focus`（出厂不设，按下时没在专注就按 25 分钟开始、专注中就结束）；周信统计加 `sunny_points`
   （关闭晴天收集时不出现）；设置页的程序名单可从正在运行的程序中选（命令 `running_apps`，只有可执行文件名、去掉系统进程，
   只在本机用）。小精灵加“专心”造型：`tools/gen_sprite_lottie.py` 在 sleep 之后加 4 秒的 `focus` 段（眯眼、两道小眉毛、
   呼吸放慢、不眨眼），专注计时中睁眼的循环换成它；原有各段的帧号不变。

## 影响
- 10 第 2.4 节 `comp` 加 `invalid`；第 6.1 节加 `moodflow.rewrite_style` / `rewrite_clipboard` / `rewrite_insert_apps`；
  第 6.2 节去掉 `rewrite.default_style`，加 `hotkey.focus`；第 5.1 节加 `running_apps`。
- 04 第 3 节 R1b 去掉“待 A 决定”，写明判定；06 FR-RWR-06 写明说明的位置；07 第 1.2 节深色 `--mf-text-3` 改值。
