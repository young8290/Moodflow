# 0059 正式市场上线前支持明确公钥的签名目录

- 状态：提议（待产品与 E 评审）
- 日期：2026-11-09

## 背景与决定

ADR 0054 的正式索引仓库和发布签名密钥尚未配置。Windows 先实现完整签名客户端，但不生成临时的「正式」公钥、不把自选来源标为官方审核。出厂无签名源，不自动联网。用户可以明确录入一个 HTTPS 索引地址、公钥和名称，勾选信任后使用；界面展示公钥指纹，说明须另行核对来源。正式市场配置及审核发布仍待 E 接入。

信任配置、签名原始字节和 revision 由输入核心保存，不在浏览器保存；Hub 仅在明确刷新或下载时取有界 HTTPS 字节，拒绝重定向、URL 凭据及查询参数。签名文件为 `<index URL>.sig`，十六进制 Ed25519。安装时核心再次检查当前来源 revision、签名、索引新鲜度、兼容版本、文件长度／SHA-256 和新增权限。更换来源或刷新使旧预览失效。

索引使用 RFC 3339 `generated_at`，容忍 5 分钟未来偏差，7 天后禁止安装。较旧索引、同一时间不同内容、遗漏历史撤回均拒收。缓存撤回在离线、过期、重启、手动启用和本地包安装时继续生效；信任文件损坏时第三方插件加载失败，不静默跳过策略。清除或更换信任源会明确提示同时清除旧源的撤回限制，须用户确认。

社区入口只打开 Moodflow 的 GitHub 问题页、提交页和现有插件设计说明，不内嵌第三方登录；没有伪造尚不存在的索引仓库链接。

## 影响

- 产品书 07 FR-SET-12 与插件计划 P6/P7：增加自选签名目录客户端；官方目录、审核流水线及正式密钥仍单列验收。
- ADR 0058：本地文件安装继续标「未审核」，自选签名只证明字节对应所信任公钥，不改变审核属性。
- Windows 完整版：商店、更新、撤回和社区功能可以针对实际签名目录验证；正式市场上线与安全评审不能由合成测试替代。
