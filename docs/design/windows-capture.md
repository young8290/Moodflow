# Windows 捕获工作台

范围依据 `xsime-extended-plan.md` §4.5。Android 不在本轮实现范围内。

## 使用与平台边界

Hub 看板的「捕获」页提供显示器／指定窗口截图、冻结图像后物理像素区域裁剪、0–10 秒延时、滚动截图、最长 120 秒录屏与 GIF。全局 `hotkey.capture` 出厂为 `ctrl+shift+a`，清空即可禁用；只打开工作台，不直接开始采集。原输入法的 UI 诊断截图动作保留。

采集与图像解码均在独立 `moodflow-capture.exe`，不进入 TSF。WGC 优先，只有显示器截图允许 DXGI 回退；指定窗口失败时不会改为拍摄它背后的桌面。录屏使用 Media Foundation H.264／AAC，声音仅为用户勾选的系统输出回环，无麦克风。GIF 不含声音。窗口尺寸变化时结束并拒绝发布本次记录。

滚动仅作用于用户选定且 PID 未变的前台窗口。每次滚动前复核目标，逐像素验证重叠；固定栏需要先框选正文。不可靠重叠会终止任务；不猜测缺失画面，不回退为别的应用截图。滚动位置不会自动恢复。

编辑提供矩形、箭头、自由画笔、纯色遮挡、文字、撤销、比例裁剪、十字线、像素放大镜、留白、圆角和阴影；保存生成新 PNG，保留原记录。取字使用 Windows 离线 OCR，未装可用语言包时明确提示；二维码只返回文字，不自动打开链接。结果经用户审核后才可加入 Buffer，暂存不授权或触发投递。

贴图是独立受保护的置顶窗口，可拖动、调整透明度、穿透；穿透后可从工作台恢复交互或关闭。图片复制同时提供 PNG 与 CF_DIB，标记排除历史、云剪贴板和监测处理；不模拟粘贴。识别文字复制使用原生敏感剪贴板租约，最多 60 秒，仅清理仍属于这次复制的内容。

## 隐私和生命周期

核心 `tools.captureAllowed` 复用密码／安全桌面／无痕判断及 Tap 实时用户应用名单；只有显式工具忽略自有 Hub 的被动采集排除。显示器目标保守检查相交可见窗口的进程身份，可能包含被其他窗口遮住的应用；无法取得身份则拒绝采集。

Hub 每 50 ms 检查取消和本地隐私，核心许可最长有效一秒；首次拒绝后整次任务失效。辅助进程另行检测交互桌面、WTS 活动会话、密码焦点；比较包含睡眠的 uptime 和不含睡眠的 interrupt time，睡眠后永久取消该任务，不能因解锁或恢复而继续。暂停事件立即设置取消标志。进程使用 Windows Job Object 限制内存并在 Hub 退出时终止。

结果尺寸限制为 6400 万像素、32768 长边，单资产 512 MiB，输出文字 65536 UTF-16。请求、标准输出、标注点数、窗口数量及处理时间均有界。异常输出只返回固定错误代码，正文、像素、OCR、标题和文件路径不进日志。

## 文件和清理

资产位于本机工具数据目录的 `capture/`，继承当前用户专属 DACL。文件名 UUID，索引保存 SHA-256、尺寸与长度；读取、导出和删除复核内容，索引以锁和临时文件原子发布，不自动重建损坏索引。导出不覆盖已有文件。

临时资产保留 30 天，总量上限 10 GiB；写入前为新文件回收最旧的未租用临时资产。贴图和正在处理的资产受租约保护；存入资料库后标为永久，不自动清理。删除永久附件需要单独确认。Hub 下次启动只清理固定命名的遗留工作目录和已知临时文件，不递归跟随链接或删除不认识的文件。

## 验证与尚待运行验收

常规测试只使用合成图像／二维码、临时目录和模拟前端事件，不读取用户桌面。已覆盖 PNG 解码、QR 往返、视频颜色／行序、GIF 时长、滚动精确重叠、睡眠撤销、保留压力与租约、外部篡改和损坏索引保护、暂停后异步结果与导出对话框失效。

Windows CI 的忽略测试必须先确认 `GITHUB_ACTIONS=true`，再创建并仅捕获专用合成窗口，验证真实 WGC、离线 OCR 与 H.264。三屏混合 DPI、RDP／锁屏／睡眠、真实音频回环、长图和安装包操作仍需运行验收；测试未执行前不将这些项登记为通过。

辅助程序由 Windows 全构建一起生成，走相同 MSVC／静态 CRT／签名流程。打包拒绝缺失该文件的 Hub 产物。当前无商业签名证书，构建接入不等同已获得可信签名。
