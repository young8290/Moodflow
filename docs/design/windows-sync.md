# Windows 同步

Hub 的同步页把用户明确选定的资料写入自己的文件夹或 HTTPS WebDAV。无 Moodflow 账号、无自建服务器、无后台定时任务；每次开始须明确确认，暂停、锁屏、睡眠、会话失活、隐私闸门关闭会取消本次操作，解除后不自动继续。Android 应用未修改。

## 范围

默认同步笔记、技能和文献元数据；不扫描剪贴板、工作区、日常密码库或捕获临时文件，不跟随资源指向的文件。文献正文中的本机附件路径、资源类条目与非文献扩展属性不上传；本机非同步属性在接收远端版本时保留。文献属性中显式的本机路径字段、`file:` 地址、盘符与 UNC 路径也被排除。笔记和技能正文是用户选择同步的文本，不会分析或读取其中提到的文件。

密码库只支持单独选择的 `.mfvbackup` 备份副本：先用其独立恢复短语核验，再加入同步副本区。每次同步须另外勾选，且仅端到端加密模式允许传输；默认不接收或上传这类副本。对端得到的仍是独立加密备份，须导出文件并在密码库中核验恢复为新库，不会合并或替换正在使用的密码库。日常库主密钥、DPAPI 包装和主口令不会进入此通路。备份冲突也保留为加密文件，不转成明文笔记。

## v1 协议与加密

- `moodflow-sync` 是纯逻辑 crate，平台访问以 `Backend` 和 `Local` 注入。同步目录固定使用所选位置下的 `MoodflowSync-v1/`，只读取已知协议文件；本机配置、三方基线、冲突和备份副本位于私有工具目录 `sync/`。
- `config.mfsync` 记录版本、随机数据集 UUID、随机 16 字节盐及加密校验值。恢复短语至少 24 字符，固定 Argon2id v0x13（64 MiB、3 次、1 通道、256 位输出）；远端不能提供任意 KDF 资源参数。
- XChaCha20-Poly1305 使用随机 24 字节 nonce，AAD 包含协议版本、数据集 UUID 和对象用途／条目 UUID。`index.mfsync` 为加密清单，`objects/<密文字节 SHA-256>.mfsync` 为内容寻址的加密对象；文件名不含标题或正文。
- 恢复短语与派生密钥不实现 Debug，不写配置或日志；原生命令副本退出时清除。WebDAV 密码每次填写，不自动复用其他服务凭据。明文模式须单独确认，不能承载密码库备份。
- 每个副本固定数据集身份和配置文件哈希；远端重建、降级加密方式或更换资料集不能抹除已有基线。清单、对象、解密结果分别受数量／字节上限与身份校验约束。
- 普通资料仍受 Capsule 单条 2 MiB 限制；协议对象最多 16 MiB，以容纳独立密码库备份，合计最多 256 MiB、活动条目最多 10,000、含永久删除标记最多 50,000。冲突和备份副本另有本机数量与容量上限，满额即停止，不自动丢弃原稿。

## 合并、失败与恢复

使用本机内容 revision、同步端内容 revision 和上次成功基线做三方判断，不依赖设备时间。双方同时编辑时同步端版本胜出，本机败者先存 `sync/conflicts/`；恢复冲突只能另存为新 UUID，不能覆盖原条目或复活删除标记。永久墓碑优先于内容；新设备也记录已删除的未知 UUID，阻止后续隐式导入。媒体／对象缺失、OneDrive 未下载属性与暂时不可用都只延后，绝不据此删除。

先写不可变对象，再条件更新清单；清单 CAS 成功之前不替换本机资料。替换或删除时，Capsule 再次验证实际磁盘 revision。每个成功应用的本机变更单独推进基线；即使后面失败或取消，也保存已完成检查点。失败可能留下未引用的加密对象，v1 不做远端垃圾回收。

文件夹通过有界文件锁、原子替换及写前复验协调；同步服务自身不参与本机文件锁，网盘复制完成前应等待其收敛。检测到网盘生成的根目录冲突文件时先停止常规同步。“处理网盘冲突”验证同一数据集的清单，合并新增条目与永久墓碑，保留冲突内容；规范清单中的活动版本优先。成功后仅将已校验的冲突源文件移入同步目录 `provider-conflicts/`，不删除原文件内容，再由用户重新执行同步。无法验证或尚未下载的副本不会被覆盖或移走。

WebDAV 仅 HTTPS、不含 URL 用户信息、不跟随重定向，使用独立用户名／密码字段；固定相同目标下的协议路径，不浏览其他目录。`GET` 要求清单提供强 ETag，`PUT` 使用 `If-Match` 或 `If-None-Match: *`；服务不支持安全条件更新时拒绝继续。连接 10 秒、单请求 20 秒，响应和上传流均有字节限制及取消检查，整个显式任务最多 10 分钟；需要时由用户重新发起。

删除全部 Hub 数据只移除本机同步配置、基线、冲突和备份副本；不会按配置内容删除外部文件夹或 WebDAV 文件。导出的外部备份也保留。

## 验证与发布边界

协议测试使用两份合成副本，覆盖交替离线编辑、冲突副本、永久删除、占位／缺失延后、清单 CAS 失败、本机并发编辑、取消、密文篡改、错误恢复短语、跨数据集和跨对象重放，以及网盘冲突清单恢复。

Windows 原生测试使用实际临时目录与回环 HTTP 模拟 WebDAV，验证资料路径排除、本机路径保留、文件条件写入、真实认证／ETag／条件请求／拒绝重定向；独立密码库备份经过加密传输与恢复解密往返，未访问日常密码库。界面验证明确同意、密码库副本默认排除、秘密清理、暂停后的迟到结果与文件选择器失效。

尚未把真实网盘账号、两台独立设备上的文件提供程序与桌面安装操作登记为通过。密码库和同步加密格式须按二期计划交 E 安全评审；本实现不以单元测试代替该评审。完整交付状态继续记录于 [Windows 交付清单](xsime-windows-delivery.md)。
