# Android 并击方案管理

入口：Moodflow 设置 → 滑动并击与键位 → 管理并击方案。

用户可以新建、复制内置、导入 Windows/Moodflow 的版本 1 JSON、搜索并编辑组合、导出草稿。保存草稿、保存并启用、切回内置分别是独立操作；切回内置后仍可继续编辑已保存草稿。文件只通过 Android 文件选择器读写，输入和导出均为 UTF-8，导入上限 256 KiB。

Android 触屏每手一个触点，可按起点与终点给出至多两键。为避免启用后出现无法按出的组合，应用拒绝未知键、重复组合、仅含一键的映射、任一手超过两键的映射，以及会挤出触屏行的布局。键区支持 a–z、逗号和句号，有效映射最多 1024 条。桌面 JSON 可能用了手机无法表达的键位，导入时会提示具体限制。草稿可以没有映射；启用前至少要有一条。核心继续负责版本 1 格式和结算校验。

Android 应用目录用单个原子快照持久化草稿和启用版本。编辑器提交前复核快照，过期编辑不能覆盖另一个窗口的保存；只有启用版本发生变化才通知键盘。键盘同时换掉 Rust 结算器和触屏模型，取消旧手势和物理键定时器；有旧键松开时只消化回执，不喂给新方案。内置跨手滑动路径按当前映射查拼音，只有新方案包含该映射时才可用。无法加载自定义方案时键盘回到内置方案。

此模块不引入 Rime ZIP 导入或新的两段触屏结算；两者单独推进。真机需验证 Android 文件选择器、换屏后激活、软键盘与外接物理键盘的实际行为。
