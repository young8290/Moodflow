# Android 触屏输入

在「设置 → 滑动并击与键位」可开启两段手势并击（A5）。同批按下的手势仍在最后一根手指抬起时结算。开启两段后，单手已经抬起且组合能接另一只手时才等待。另一只手及时开始后可继续滑动，最终匹配当前方案才合并。等待窗口使用当前方案的组键间隔。超时或没有组合映射时，原本可独立结算的手势仍可输出。关闭、换输入框或隐藏键盘会丢弃等待中的手势。

九宫格选中前缀候选后（A12），键盘按核心剩余原码裁掉已经消费的按键。已选汉字留在组合区，后续数字输入和删改只替换尾部。末段为自动补全时，保留实际按下的数字。退格删空尾部后可再退回前一段。

中文 123 页和符号页按键面直接上屏（A9），数字不会误选词，半角小数点不会受全角设置影响。普通标点入口仍由核心提供源键映射。两端键面数据合并另行跟踪。

真机验收时分别检查紧凑和分体键区、同手连按、跨字段取消、九宫格逐段选词后继续输入或退格，以及候选尚未确认时在中文数字页输入 `3.14`。
