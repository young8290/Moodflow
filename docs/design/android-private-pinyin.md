# Android 无痕中文输入

带 `IME_FLAG_NO_PERSONALIZED_LEARNING` 的普通文本框可用 26 键全拼。候选支持翻页、矩阵和点选。外接键盘支持拼音输入、数字选词、翻页、退格与 Esc。空格确认当前页的首选，回车保留原码。中英切换只对当前字段有效。设备没有可用的出厂拼音词库时，键盘提示并允许直接输入。密码框和数字类输入仍沿用直接输入。

该路径不向普通协调器提交按键或选词事件。移动端只持有出厂词库的查询器，后台准备词库缓存时没有字段内容。每次查询只用当前拼音，不接受用户词库、配置、统计、插件、Buffer、剪贴板或外部上下文。组字与候选只留在当前 Android 输入会话，换字段、失焦或隐藏键盘时清除。音节长度与候选数量均有上限。

验收入口是设置中的「输入体验」。在无痕框内输入并选词，切到普通框和密码框再返回，确认没有遗留候选。在外接键盘上测试数字选词、分页和中英切换。重复选择一条候选，确认普通输入排序、用户词和统计不变。
