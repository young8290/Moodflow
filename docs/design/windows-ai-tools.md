# Windows 文字、公式与参考文献工具

Dashboard 的「文字与公式」提供生成、改写、问答、翻译、诗词、图像提示词、LaTeX 和有来源的引用段落。图像提示词输出文字；本功能不生成图像。离线 LaTeX → Unicode 无需联网或配置模型。

## 主动发送与结果处理

每次请求先展示选定模型和服务地址，由用户勾选同意。参考文献请求还需单独同意向 Crossref 发送检索词；只有该动作会检索公开元数据和摘要。未选模型、配置变化或服务失败时明确停止，不切换模型或提供商。工作区与工具共用模型网关、输入与输出防护、暂停、锁屏、安全桌面及睡眠取消。Mock 仅在开发模式使用并标明。

输入、图片、摘要和最终请求均经过现有防护。暂停或编辑输入撤销在途请求，过期结果丢弃。正文和图片不写日志，不自动保存聊天历史；结果由用户编辑后显式加入 Buffer，暂存不授权投递。

## 公式与图片

公式可手动输入，或由用户明确选取最多三张 PNG/JPEG。图片先由独立辅助进程解码、规范化为 PNG 并去掉原始附加元数据，再进行本地 OCR；仅规范化像素及所需文本发给选定模型。每张原文件与规范化图片分别限 4 MiB；临时目录按请求释放。不能传远程图片 URL。

预览使用随包 KaTeX 0.19.1，禁用信任、外部链接、图片、HTML 和宏定义，并限制长度、嵌套、展开量与尺寸。无法解析时保留文字和错误说明。纯 Rust Unicode 转换支持常用希腊字母、数学符号、分数、根号和上下标；不认识的命令保留并列出，不执行 TeX 或文件操作。

## 来源与模型边界

参考文献从 Crossref HTTPS 官方接口按用户检索词取得至多四条含作者、日期和摘要的来源；20 秒、1 MiB 限额，拒绝重定向。模型只取得这份来源列表，生成段落后的编号必须全部对应实际来源，引用格式由本地 `moodflow-cite` 生成，不能由模型编造 DOI 或书目。元数据和摘要不代表已核验论文结论，界面仍需用户审阅。

模型请求只接受已配置的精确模型标识，响应模型必须一致、正常结束，单次最多 2,048 token、60 秒、1 MiB 和 16,384 个 UTF-16 码元；服务返回别名、截断或空正文均拒绝。使用将别名解析成另一版本标识的服务时，须配置其实际响应标识。
