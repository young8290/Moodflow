# Windows 签名插件商店与社区

Hub 设置 → 插件分为已安装、商店和社区。出厂没有配置正式市场，不自动联网；自选来源须填写 HTTPS 索引地址、64 位十六进制 Ed25519 公钥和名称，核对独立渠道提供的公钥后明确同意。界面展示公钥 SHA-256 指纹。签名证明文件属于这个公钥持有者，不代表 Moodflow 官方审核。正式市场发布流程与公钥仍待 E 配置，决策见 ADR 0059。

## 使用与安装

主动刷新只取索引和 `<索引地址>.sig`，不发送输入或密钥。Hub 拒绝重定向、URL 凭据、查询参数和非标准端口；索引最多 1 MiB，签名最多 256 字节，插件包最多 32 MiB。源和包都只能 HTTPS。社区按钮在系统浏览器打开固定的 Moodflow 问题、提交和插件说明页面。

信任和缓存位于输入核心自己的 `plugins/.moodflow-market.json`，与便携或自定义用户目录一致。浏览器不保存信任。核心验签后检查索引结构、重复标识、兼容性、包长度及 SHA-256；下载预览列出插件用途、来源和新增权限，确认后再次复核当前索引 revision 与包字节。配置或刷新改变后，旧预览失效。首次安装在用户同意权限后启用；升级保留原启用状态。安装不访问输入正文，逐键插件原有隐私与禁联网规则继续由沙箱执行。

## 时效、撤回与失败

`generated_at` 必须是 RFC 3339，最多容忍未来 5 分钟，7 天后不能用于新安装。旧时间、同一时间不同内容、遗漏历史撤回记录的更新均拒收。签名、下载、核心离线或权限失败不会安装半包。已缓存的撤回长期生效：核心重载、重启、手动启用和本地包安装都会检查。损坏的信任文件阻止第三方加载，已安装列表显示原因；须修复记录后继续，不自动恢复为无限制状态。

更换或清除来源会清除旧来源的缓存限制，界面要求明确确认；已安装插件及私有数据保留。清除前应确认不再需要旧来源的撤回限制。本地文件安装继续显示未审核，签名来源的审核资格不由客户端自行授予。

## 已验证与待验收

- 市场、注册表和数据 RPC 147 项测试及输入工作区全目标 Clippy 通过。测试使用真实签名和 ZIP、临时磁盘策略，覆盖篡改、大小／时钟限制、并发 revision、权限拒绝、确认前文件替换、安装、离线撤回、重启和损坏策略。
- Hub 实际回环 HTTP 测试验证不跟随重定向和响应限额；前端定向 24 项通过，包含明确同意、来源更换、权限展示、一次预览 token、取消旧结果和外部内容按文本显示。
- 尚未连接正式市场或完成产品与 E 的策略评审；不以自选目录或合成签名替代官方审核。
