# 资料库批量迁移与管理

分支：`codex/library-batch-migration`。在资料库页面展开“批量迁移与管理”。

## 交付范围

- 一次选择多个 Markdown 文件或 `.mflibrary` 迁移包，读取后先展示预览，不写库。
- 区分新资料、相同内容、版本冲突、本批重复标识、已删除及损坏资料。
- 新资料默认新增；其他默认跳过。可逐条另存为新资料；正常已有资料可明确替换。
- 替换携带预览时的磁盘 revision，沿用库的跨实例锁与发布前复核。不会将迁移包中的 revision 当作覆盖授权。
- 确认时重新读取全部源文件并核对 SHA-256。任一源变化或无效，在任何写入前拒绝本批。
- 每条独立提交，显示成功、跳过、冲突和失败。部分成功不会回滚；已成功的行在当前预览中禁止再次执行。
- 勾选当前列表中的资料，导出可往返的版本化迁移包。导出核对所有所选 revision，在同一库锁下形成快照，再原子发布到新文件；不覆盖已有文件。
- 保留未知元数据、文献字段、标签和正文；不打开、复制或自动执行资源引用。包内可能包含本机路径，界面明确提示。

## 有界格式

迁移包是 UTF-8 JSON：`format: moodflow-library`、`version: 1`、`documents: Document[]`。
每批最多 200 条、源文件合计最多 32 MiB；单条沿用 2 MiB 上限。
不接受明文密码类型或密码/密钥字段。目录和链接不是导入源；不递归扫描目录。
导入只进入资料库，不向输入框或 Buffer 自动投递，不联网。

普通 Markdown 的预览标识由规范源路径和内容摘要确定；同一路径相同内容再次导入能识别已有资料。
另存会生成新的 UUID；已删除标识的墓碑始终保留，不做隐式复活。

## 验证与人工验收

核心回归覆盖包往返和未知字段、源变化、并发替换冲突、部分成功、复制已删除资料、跳过、重复输入、损坏资料和配额。
前端回归覆盖默认选择、替换授权、未保存编辑保护、确认取消、源变化提示、成功行禁止重试、导出版本快照和 200 条上限。

人工桌面步骤：
1. 准备两份普通 Markdown 和一个含未知字段的资料包，预览后取消，确认库不变。
2. 确认新增，重新选择同一批，核对相同/冲突状态；明确替换其中一条、另存另一条。
3. 预览后外部修改源文件，确认导入被拒绝；重新预览后继续。
4. 在另一个窗口修改待替换的资料，确认冲突保留本机新内容，并显示其他条目的成功结果。
5. 勾选导出，换新资料库重新导入，核对正文、标签及未知字段。资源附件不会随包出现。
6. 导出前外部修改已选资料，确认旧 revision 被拒绝；选择已有目标文件，确认不覆盖。
7. 在导入预览或编辑期间暂停/恢复，确认隐私页面隐藏，未授权状态拒绝命令。

原生文件对话框往返与完整用户桌面交互仍需实际验收，不由单元测试替代。
