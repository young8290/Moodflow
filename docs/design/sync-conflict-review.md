# 同步冲突对比与手动合并

分支：`codex/sync-conflict-review`。独立基于主分支，不包含资料库迁移或工作区检索 PR。

## 使用流程

同步页的冲突中心替代原先只能预览单份正文的区域。按标题、标签或原资料 UUID 筛选；同一资料的不同版本相邻排列，每页 20 条。可切换到“替换前备份”，对替换前版本进行同样的核对与恢复。

选中副本后展示当前资料状态、逐行正文差异、最多 64 个元数据差异字段和可展开的左右全文。支持手动编辑标题、标签和合并正文，以及一键采用当前正文或副本正文。默认另存为新资料；仅当前可读、类型一致的笔记/技能允许合并到原资料。文献只可另存元数据，不修改本机附件路径。

切换副本、切换来源或离开同步页时，未保存的合并编辑需要明确放弃。隐私暂停会卸载组件、清空正文与操作意图，迟到的确认不触发保存。

## 保存与恢复契约

- 副本文件名为规范 UUID + 原始字节 SHA-256，读取时校验内容摘要及内嵌 UUID。不合格文件隔离显示，既不重建也不自动删除。
- 合并携带源摘要与当前磁盘 revision，保留当前资料的其他未知元数据。替换前把当前文件的原始字节完整保存到 `sync/recovery/backups/`，再由资料库执行 CAS 发布；并发新编辑不会覆盖。
- 副本与替换前备份默认保留。用户可在确认后删除选中的本机副本；删除检查预览摘要，不改变当前资料、远端数据或删除标记。
- 缺失、已删除、损坏或类型变化的当前资料都不能隐式恢复原标识，只能另存新资料。原墓碑保留。
- 另存使用客户端为本次编辑意图生成的规范 UUID 和固定更新时间。相同请求重试只认可完全相同的已保存结果；不同内容或 ID 冲突拒绝，避免响应丢失后重复创建。
- 备份失败、容量不足或隐私许可撤回时停止保存。备份可能已成功但 CAS 随后冲突时，保留备份与两份原稿，不自动重试覆盖。
- 所有操作只访问本机，不运行同步、不写远端、不修改同步基线。备份目录不自动纳入同步，显式“删除全部工具数据”仍覆盖整个 sync 目录。

## 边界

单条沿用资料库 2 MiB 上限；每个副本目录最多 1000 项、256 MiB，备份达到上限时拒绝新替换。根由宿主设置为当前用户私有目录；文件拒收链接/重解析点，路径只能由严格文件名构造。恢复控制锁等待最多两秒，期间持续检查隐私许可。

逐行比较最多读取两边各 4000 行；LCS 矩阵最多 500,000 单元，超过后采用公共前后缀的有界比较。更长文档不展开逐行计算。界面最多显示 400 行差异/上下文，每行最多 512 字符；较大值和比较截断有明确提示，仍可展开全文。省略未变化的长段，使后部变化能够出现在预览中。不执行自动三方合并，也不把“当前资料”和“保留副本”伪装成共同祖先。

## 验证

核心回归：原始字节备份、未知元数据保真、复制重试、保存前/保存期间的并发修改、源篡改、墓碑、缺失/损坏隔离、备份再次恢复、暂停、配额失败、显式删除和 Unicode/大文档差异边界。
界面回归：默认另存与最终确认、纯文字呈现、当前 revision 授权、操作 ID 复用与编辑后更新、未保存编辑保护、备份来源、已删除条目的保存方式、迟到确认和比较简化提示。

人工验收使用独立测试账户/合成资料：
1. 制造同一笔记的两个冲突版本，对比前后部改动和元数据，编辑合并结果。
2. 合并前在另一实例编辑当前版本，确认拒绝覆盖；重新载入对比后处理。
3. 成功替换后切到备份，核对原始正文和未知字段，另存恢复。
4. 预览后修改副本文件，核对摘要拒绝；删除当前资料后只允许新建。
5. 保存确认框打开时暂停并恢复，迟到确认不保存。切换页面时取消放弃，编辑仍保留。
6. 明确删除一个合成副本，确认当前资料与远端不变。

未执行的完整桌面交互仍需人工记录，单元测试不代替该验收。
