# Windows 密码库

当前为待安全评审的实现；尚未作为正式安装包发布。Android 未接入。

## 持久化格式

`moodflow-vault` 不依赖 Windows、Tauri 或网络。条目使用独立随机 nonce 的 XChaCha20-Poly1305，AAD 绑定格式版本、库 UUID 和条目 UUID；整份快照再加密，磁盘不暴露标题、账号和索引。写入执行 SHA-256 revision CAS、目录锁和原子替换，拒绝覆盖并发修改和自动重建损坏文件。

主密钥为随机 256 位。口令用 Argon2id v0x13（64 MiB、3 次、1 通道）派生包装密钥；这些参数由 KeyWrap v1 固定，改变参数必须迁移格式。包装记录再经当前 Windows 用户的 DPAPI 保护。目录 DACL 只授予当前用户。库不参与普通资料搜索、AI、Buffer 或默认同步。

日常库格式绑定 Windows 用户配置文件，仅复制库文件与知道主口令不足以在另一用户或重装后的配置文件恢复。迁移使用显式导出的 `.mfvbackup`：每次生成独立的随机密钥与 UUID，以至少 24 字符的恢复短语经 Argon2id 包装，再用 XChaCha20-Poly1305 加密整份快照。备份不携带日常库的主密钥或 DPAPI 包装，备份密钥不能解锁日常库。

恢复先解密验证并只返回条数和源文件 SHA-256，用户确认后重读文件复核哈希；只允许目标尚无密码库。新建随机日常密钥，按新主口令及当前用户 DPAPI 重包装，条目重新加密。备份导出不覆盖已有文件，恢复不替换已有库。同步尚未接入。

## 解锁与剪贴板

原生层持有不续期的 60 秒解锁租约，后台每 500 ms 清扫；暂停、非交互桌面、切换页面及退出均锁定。字段显示最多 15 秒，返回明文前再次检查隐私和租约。密码、口令和 TOTP 密钥不实现 Debug；Rust 临时缓冲和 Argon2 内存清零。WebView、IPC 和系统的复制不能承诺取证层面的彻底清零，安全评审须覆盖这一边界。

复制只由原生层执行，先发布 ExcludeClipboardContentFromMonitorProcessing、CanIncludeInClipboardHistory=0 和 CanUploadToCloudClipboard=0，再发布文本。每次复制生成随机 128 位归属标记；到期或锁定后在剪贴板锁内核对系统所有者 HWND 与标记，只清除仍属于本次操作的内容。单用 sequence 会被 Windows 在关闭或合成格式时的变化误导，已由真实 CI 用例检出。打开失败则重试，不清除用户后来复制的内容。不自动填充或模拟粘贴。
