# 并击试练台

Windows Hub 路径：设置 → 输入法 → 输入工具 → 并击方案编辑 → 并击试练台。

先在编辑器修改、复制内置方案或导入 JSON，再打开试练台。它试用编辑器里的草稿，支持在保存或应用前发现错键与不合适的两手间隔。

- **自由试打**：聚焦试打区后按下按键。左右键区会标出正在按住的键。松开所有键后，结果区显示实际识别到的组合、拼音或未匹配结果、总按键历时和每次结算时点。
- **组合练习**：可选练习单手、双手或全部组合，每轮最多八题，可显示键位提示。同一拼音对应多个组合时，按当前题的键位和输出判分。按错可重试，也可跳题。轮末分别显示通过题数、首试通过和总试打次数。
- **隔离**：记录和成绩只保留在当前页面。关闭试练台、编辑草稿时清空记录；焦点离开试打区时清除尚未提交的按键。按键反馈不会投递到输入框、改变已应用方案或写入用户词库。

## 契约

Hub 的受限工具命令经本机 RPC 调用 `chord.rehearse`。请求带草稿 JSON 和按键轨迹，空轨迹用于方案校验和物理键解析。服务使用与运行时相同的键名表，区分无效方案、空映射、不支持的物理键和不同别名指向同一个物理键。试打区按字母及标点的标准键位显示，不读取输入法组合区或系统的全局键盘事件。

回放由新的 `moodflow-chord::rehearse` 调用真实 `Settler`。输入时间以第一下按键为零点，并保持单调；前端在全部松开后等待方案间隔再提交一次试打。回放末尾推进一个空闲间隔，让等待另一只手的组合能在试练台给出结果。Windows 正常输入时，挂起的半组仍可在下一次参与并击的按键到来时结算，此改动没有调整正常输入的调度。

单次最多 128 条按键转移、120 秒和 512 KiB 草稿；不接受残缺或乱序轨迹。前端最多展示最近 12 次试打。接口不读写配置文件，不管理常驻会话，不需要联网。

## 验收

自动测试覆盖同按、先后按、间隔恰好超时、片段输出、非法时间与丢失松开事件；前端覆盖键盘捕获、失焦、异步草稿切换及同音不同组合的判分。Windows 真机还需验收 WebView2 焦点、不同键盘布局及真实设备的多键无冲。
