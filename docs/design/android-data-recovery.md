# Android 数据安装与恢复

APK 构建对实际打包的出厂文件生成版本 1 的 SHA-256 清单。首次启动和 APK 更新后，应用按清单把文件流式写到私有临时目录，逐项核对长度和哈希。全部通过后才切换 `filesDir/data`。如果解包失败，旧目录保留。如果应用在切换两步之间退出，下次启动先找回旧目录，再重试。完整安装记录与出厂目录一起发布。同一版本的后续启动沿用已安装目录。用户词库、配置和历史在独立目录。

从早期 Android 版本升级时，若本机仍有 `filesDir/rust/clipboard.json`，设置的剪贴板页会显示「恢复旧版剪贴板历史」。开启历史并确认后，恢复在后台执行。重复条目保留当前 ID、最新复制时间和收藏。未收藏条目遵守当前保留期和条数。恢复结果和完成标记一起写入，后续重新启动或点击不会恢复已经删除的条目。解析或写入失败时提示结果，旧文件继续留在本机。

验收时可安装旧 APK 并记录文本、链接及收藏，再保留应用数据升级。验证恢复、重复点击、关闭历史后的行为，以及出厂数据解包期间退出后重新启动。
