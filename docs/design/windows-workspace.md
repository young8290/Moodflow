# Windows 工作区

工作区与晴晴信箱、晴晴对话分开。Hub 的工作区页包含对话、收件和终端，数据位于变体感知用户目录 `workspace/`，采用当前用户私有 DACL。Android 应用未改动。

## 会话与内容

`moodflow-mailbox` 不依赖平台、网络或 AI。UUID JSON 文件通过目录锁、磁盘 SHA-256 revision 和原子替换保存；删除留下永久墓碑，损坏不会静默重建。最多 200 个会话、每会话 200 条、单条 16384 UTF-16、每会话 8 MiB、全部消息 128 MiB。附件每份 32 MiB、总计 128 MiB，以随机 UUID 保存并校验 SHA-256；只通过用户文件选择明确关联会话，不按路径或文件名猜测。

收件输入框只写本地备注。外部文字按普通文本显示，审核编辑后才能显式暂存 Buffer；暂存不选择输入目标、不授予投递授权、不模拟粘贴。文件不能自动执行，收件接口也不接受文件路径。Hub 暂停隐藏正文并使旧异步结果作废。

对话首次发送冻结服务地址的 SHA-256 身份和实际模型，不保存含查询参数或账号的原始服务地址；后续配置改变不能静默换模型。可选会话指令由用户填写，出厂为空且首次发送后冻结，没有新增出厂 AI 提示词。每次 AI 请求须明确同意，历史只有勾选后发送；本地备注、附件和外部收件不混入对话历史。所有实际发送内容使用现有危机词表和 Jev 危机检测，返回再过禁用词／危机检查。共用 AI 网关的凭据、预算、脱敏和超时；严格校验模型身份、完整结束标记与输出上限，不自动重试或改用其他模型。失败保留用户消息，不保存半条回答；开发 Mock 按消息标明。

## 本机只写网关

网关每次 Hub 启动默认关闭，由用户显式开启，仅监听 `127.0.0.1`。256 位随机 Bearer token 经当前用户 DPAPI 保存，复制使用原生敏感剪贴板租约，前端拿不到 token；显式轮换使原 token 与进行中的流失效。所有路径和 HTTP 方法先验证 Host、token 和 Origin；有 Origin 的浏览器请求拒绝。请求体 256 KiB，读取限时 5 秒，最多 4 个并发和每分钟 1024 次；正文和令牌不进日志。

- `POST /write`：`push`、`begin`、`chunk`、`finish`、`cancel`，只接受未归档收件会话。
- `POST /mcp`：现代 `2026-07-28` 的发现与逐请求元数据校验，兼容 `2025-11-25`、`2025-06-18`、`2025-03-26` 初始化协议。只公开五个写入工具，没有读取、搜索、资源访问或终端操作。
- `push` 指定 `session_id`、UUID `message_id` 和 `text`；同 id 同内容重试只返回回执，不重复写入。变更内容拒绝。
- `begin` 指定 `session_id` 和 UUID `stream_id`；`chunk` 从序号 0 连续写入。最多 16 条在途流、每条 2 分钟，失败／失序／超限清除，不落盘。
- `finish` 同时指定 `session_id` 和 `stream_id`，完整消息原子保存后才返回固定回执。回执丢失后的重试，包括重启后的重试，只确认已有消息 id，绝不回传正文；错误会话拒绝。`cancel` 只撤销内存流。

示例仅含占位符（不要把真实 token 写进脚本或仓库）：

```json
{"operation":"push","session_id":"<inbox-uuid>","message_id":"<new-uuid>","text":"<text>"}
```

## ConPTY 终端

终端由原生 Runtime 持有，Windows ConPTY + xterm.js 显示；用户选择目录后才启动固定系统 PowerShell。HTTP/MCP 没有启动或输入终端的接口。终端输出不是消息，不写聊天存储；原生持续读取输出，环形缓冲 256 KiB，前端回卷 1000 行，溢出明确提示。单次输入和待发队列有上限；暂停、换会话和卸载使旧输入失效。OSC 52 被拦截，输出不能读写系统剪贴板或自动打开链接。

导航、关闭 Hub 窗口不会结束进程；“结束”经用户确认后销毁自己的 Job Object，整棵子进程树退出。Hub 进程退出也会清理 Job。子进程先挂起，纳入 Job 后才恢复，内存上限 1 GiB；不继承 Hub 的标准输入输出。测试只启动自己的合成 cmd/PowerShell 进程，不操作已有用户终端。

## 验证边界

纯逻辑覆盖 revision 冲突、冻结模型、容量、墓碑、只写协议、流失败以及完成回执重试。Windows 原生测试覆盖 DPAPI token、Host/Origin/token 校验、真实 ConPTY 收发及整棵子进程清理。界面覆盖收件文本惰性显示、审核暂存、备注不调用 AI、发送同意、暂停丢弃迟到回答、文件选择器和终端按键队列跨暂停失效。

这些验证不代表已经通过真实第三方 MCP 客户端、Hub 桌面操作和安装升级验收；相关交付状态继续记录在 Windows 交付清单。密码库安全评审与未购买的代码签名证书也不因此完成。
